# Dashboard

## Overview

The Dashboard provides a privacy-preserving interface for presenting the system's monitoring results.

## Information Displayed

The dashboard may present structured information such as:

* Current activity
* Location
* Confidence
* Anomaly status
* Fall status
* Post-event movement
* Safety alerts

## Example

```text
Status: Walking
Location: Living Room
Confidence: 92%
```

For a potential critical event:

```text
Status: Possible Fall Detected
Confidence: 94%
Post-Event Movement: Low
Action: Safety Alert Generated
```

## Privacy

The proposed interface does not depend on continuous live video monitoring.

The dashboard presents human-readable structured information instead of requiring visual surveillance.
